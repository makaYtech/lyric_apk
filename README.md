# lyric_apk

Публичный репозиторий для автообновлений Android-приложения **Лирика** —
неофициального клиента ЭПОС Пермского края.

## О приложении

**Лирика** — альтернативный Android-клиент для системы «ЭПОС Образование»
Пермского края. Показывает расписание, оценки, домашние задания и профиль
ученика в более удобном виде, чем мобильный веб-интерфейс ЭПОСа.

Приложение **не является** заменой оригинального ЭПОСа. Это дополнительный
инструмент для тех, кто каждый день открывает дневник и хочет делать это
быстрее и удобнее.

## Возможности

- **Профиль ученика** — ФИО, класс, профиль обучения, список учителей
  с предметами, кабинетами, нагрузкой и ролями. Аватарки можно задавать
  локально.
- **Оценки** — по предметам и периодам, с подсветкой среднего балла,
  детальной информацией по каждой оценке и историей изменений.
- **Расписание** — на любую неделю учебного года, с учётом расписания
  звонков, пар, окон между уроками и оценок прямо на карточках уроков.
  Есть режим правок: перенос уроков, объединение и разъединение пар,
  перестановка, удаление — всё с возможностью откатить.
- **Домашние задания** — с группировкой по дню выдачи или дедлайну,
  вложениями от учителя и возможностью прикрепить свою работу.
- **Автообновления** — приложение само проверяет новые версии и
  предлагает обновиться прямо из интерфейса.

## Установка с нуля

Приложение распространяется как **APK-файл**, вне Google Play. Это значит,
что Android при первой установке покажет предупреждение — это нормально
для любого APK из интернета.

**Пошагово:**

1. Открой [Releases](../../releases) на этом репозитории.
2. Найди последний релиз (сверху списка) и скачай APK-файл из раздела
   «Assets» внизу описания. Например, `lyric-1.0.0-release.apk`.
3. Открой скачанный файл. Android покажет диалог «Установка из этого
   источника запрещена» или похожий.
4. Нажми **«Настройки»** в этом диалоге → включи переключатель
   «Разрешить установку из этого источника» → вернись назад.
5. Нажми **«Установить»**.
6. После установки открой приложение через иконку на рабочем столе
   или в списке приложений.

На некоторых устройствах (Xiaomi, Huawei, Samsung) путь к настройкам
разрешений может отличаться — ищи в системных настройках раздел
«Безопасность» → «Установка из неизвестных источников».

Обновления приложение ставит само — APK нужно качать вручную только
один раз.

## Вход в систему

Вход в приложение выполняется **той же учётной записью, что и в
оригинальном ЭПОСе**, через портал Госуслуг (ЕСИА). Логин и пароль
вводятся **не в приложении**, а на официальной странице Госуслуг —
приложение только открывает её во встроенном окне и ждёт завершения
входа. Так же работает и оригинальное мобильное приложение ЭПОСа.

**Пошагово:**

1. При первом запуске приложение откроет страницу входа Госуслуг.
2. Введи свой логин и пароль (те же, что для оригинального ЭПОСа или
   сайта Госуслуг). Если у тебя включена двухфакторная аутентификация,
   потребуется код из SMS или приложения-аутентификатора.
3. После успешного входа приложение получит токены сессии и сохранит
   их в защищённом хранилище устройства.
4. **Повторная авторизация не требуется.** Как и оригинальное мобильное
   приложение ЭПОСа, «Лирика» хранит сессию и обновляет её автоматически.
   Заново входить нужно только при смене пароля, выходе из аккаунта
   или истечении долгоживущего токена.

Пароль от Госуслуг **не сохраняется** нигде — ни в приложении, ни на
серверах. Сохраняются только токены доступа, которые можно отозвать в
личном кабинете Госуслуг.

## Автоматическое обновление

При каждом запуске приложение:

1. Читает [`docs/update.json`](docs/update.json) из этого репозитория.
2. Сравнивает версию из выбранного канала со своей.
3. Если на GitHub новее — показывает шторку с описанием изменений
   и размером APK.
4. По согласию скачивает, проверяет SHA-256 и открывает системный
   установщик.

Если пользователь отказался — обновление можно запустить вручную через
**Настройки → Обновления → Проверить обновление**.

## Каналы обновлений

| Канал | Для кого | Стабильность |
|---|---|---|
| `release` | Все пользователи, дефолт | Стабильные версии |
| `beta` | Желающие пораньше | Могут быть баги |
| `alpha` | Тестировщики | Могут ломаться |

Канал выбирается в приложении: **Настройки → Обновления → Канал
обновлений**. По умолчанию — `release`.

## Об авторе

Проект пишется одним человеком. Автор — разработчик на **Rust**, работает
с низкоуровневыми системами (Wayland, композиторы, системные утилиты),
использует Gentoo Linux в качестве основной системы.

«Лирика» — pet-проект, выросший из личной потребности: оригинальный
веб-интерфейс ЭПОСа неудобен на телефоне, а мобильное приложение не
покрывает все сценарии. Приложение писалось в свободное время, без
команды и без бюджета.
